# رودین CRM — نرم‌افزار CRM و اتوماسیون سازمانی

سامانه یکپارچه و مدرن مدیریت ارتباط با مشتریان + اتوماسیون فرآیندهای سازمانی، ساخته‌شده با Next.js 16، TypeScript، Tailwind CSS 4 و shadcn/ui.

![تکنولوژی‌ها](https://img.shields.io/badge/Next.js_16-TypeScript-8b5cf6) ![UI](https://img.shields.io/badge/Tailwind_4-shadcn/ui-10b981) ![RTL](https://img.shields.io/badge/فارسی-RTL-f59e0b)

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 📊 **داشبورد مدیریتی** | ۶ کارت KPI با شمارنده متحرک، ۸ نمودار گرافیکی (ناحیه‌ای، دونات، ستونی، رادار، افقی)، تایم‌لاین فعالیت‌ها و وظایف پیش‌رو |
| 👥 **مدیریت مشتریان** | اطلاعات تماس، اشخاص مرتبط، سوابق کامل ارتباطات (تماس/جلسه/ایمیل/یادداشت)، برچسب‌ها و فیلترها |
| 🤝 **فرصت‌های فروش** | کانبان کشیدنی ۶ مرحله‌ای (سرنخ تا برنده/باخته)، احتمال موفقیت، کانال ورودی + نمای جدول مرتب‌شدنی |
| ✅ **وظایف و پیگیری** | اولویت‌ها، سررسید با هشدار عقب‌افتادگی، مسئول، گروه‌بندی زمانی هوشمند |
| 🧾 **پیش‌فاکتور حرفه‌ای** | انتخاب مشتری و محصولات، محاسبات خودکار (تخفیف قلم/کلی، مالیات ۱۰٪)، قالب چاپ با هویت بصری رودین، خروجی PDF |
| 📈 **گزارش‌ساز گرافیکی** | گزارش‌ساز دلخواه (۵ منبع داده، گروه‌بندی‌های متنوع، ۵ نوع نمودار)، ۸ گزارش آماده، خروجی CSV و چاپ |
| ⚙️ **فرآیندساز (مثل n8n)** | ویرایشگر بصری با React Flow، ۹ نوع گره، **تست واقعی فرآیند**: اجرای گام‌به‌گام با پخش زنده (سبز=موفق، قرمز=خطا + دلیل فارسی)، داده تستی JSON، تاریخچه اجراها |
| 🤖 **تحلیل هوشمند** | تحلیل خودکار داده‌ها با هوش مصنوعی + بینش‌های قانون‌محور لحظه‌ای |
| 🎨 **تم و شخصی‌سازی** | تم تاریک/روشن/سیستمی + ۸ رنگ تأکیدی قابل تغییر در لحظه |
| 🔍 **جستجوی سراسری** | Ctrl+K — جستجو در مشتریان، فرصت‌ها، وظایف و پیش‌فاکتورها |
| 🌙 **RTL کامل** | رابط فارسی با تقویم شمسی و اعداد فارسی |

## 🚀 اجرا

```bash
# ۱. نصب وابستگی‌ها
bun install   # یا: npm install

# ۲. اجرا (حالت توسعه)
bun run dev   # یا: npm run dev
```

باز کنید: `http://localhost:3000`

> **بدون دیتابیس هم کار می‌کند!** اگر دیتابیس تنظیم نشده باشد، برنامه به‌صورت خودکار در «حالت حافظه» بالا می‌آید — همه بخش‌ها (مشتریان، فرصت‌ها، وظایف، پیش‌فاکتور، فرآیندساز، گزارش‌ساز) کاملاً قابل استفاده و ثبت هستند. فقط داده‌ها با ری‌استارت سرور به داده نمونه برمی‌گردند.

## 🗄️ فعال‌سازی دیتابیس (اختیاری — SQLite)

```bash
# فایل .env بسازید (یا از .env.example کپی کنید):
echo 'DATABASE_URL="file:./db/custom.db"' > .env

# اعمال اسکیما و ساخت دیتابیس:
bunx prisma generate
bunx prisma db push

# (اختیاری) پرکردن با داده نمونه:
bun prisma/seed.ts
```

وضعیت فعلی لایه داده در `/api/health` و بخش «تنظیمات» نمایش داده می‌شود.

## 🏗️ معماری

```
src/
├── app/
│   ├── api/                 # REST API (CRUD + داشبورد + گزارش + موتور فرآیند + AI)
│   └── page.tsx             # تک‌صفحه‌ای (SPA) با ناوبری داخلی
├── components/crm/          # ماژول‌های UI (داشبورد، مشتریان، کانبان، پیش‌فاکتور، فرآیندساز، ...)
├── lib/
│   ├── data/                # لایه داده دوگانه:
│   │   ├── index.ts         #   انتخاب خودکار: Prisma یا حافظه
│   │   ├── prisma-impl.ts   #   پیاده‌سازی دیتابیس
│   │   ├── memory.ts        #   پیاده‌سازی حافظه (بدون دیتابیس)
│   │   └── sample.ts        #   داده نمونه مشترک
│   ├── format.ts            # توابع فرمت فارسی/شمسی
│   └── types.ts             # قراردادهای API
└── prisma/schema.prisma     # اسکیمای دیتابیس (۱۲ مدل)
```

- **موتور فرآیند**: اجرای واقعی گره‌ها (ساخت وظیفه/فعالیت در سیستم، شرط‌گذاری با داده تستی، HTTP، تأخیر) با ثبت لاگ کامل هر گره.
- **قابل توسعه**: افزودن اتوماسیون واحدهای جدید = افزودن گره جدید در `WF_NODE_TYPES` + handler در موتور اجرا.
